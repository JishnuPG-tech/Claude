# Claude Assets & Iconography Specification

## 1. Iconography System
Claude uses crisp, minimalist iconography with consistent 1.5dp to 2dp stroke width:
- **Anthropic Star / Asterisk**: Custom multi-ray star emblem in terracotta (`#D97757`).
- **Navigation & Actions**:
  - Hamburger Menu: `Icons.Default.Menu`
  - New Chat: `Icons.Default.Add` / `Icons.Default.Edit`
  - Send: `Icons.Default.ArrowUpward` (custom inside circular pill)
  - Stop: Filled rounded square `■`
  - Close / Clear: `Icons.Default.Close`
  - Model Down Chevron: `Icons.Default.KeyboardArrowDown`
  - Voice Mic: `Icons.Default.Mic`
  - Attachments: `Icons.Default.AttachFile` / `Icons.Default.AddPhotoAlternate`
  - Settings: `Icons.Default.Settings`
  - Search: `Icons.Default.Search`
  - Copy: `Icons.Default.ContentCopy`
  - Check: `Icons.Default.Check`
  - Refresh / Regenerate: `Icons.Default.Refresh`
  - Thumbs Up / Down: `Icons.Outlined.ThumbUp` / `Icons.Outlined.ThumbDown`
  - Terminal / Code: `Icons.Default.Terminal` / `Icons.Default.Code`
  - Thinking / Brain: `Icons.Default.AutoAwesome` / `Icons.Default.Psychology`
  - Projects / Folder: `Icons.Default.Folder` / `Icons.Default.FolderOpen`
  - Artifacts: `Icons.Default.Description` / `Icons.Default.Article`

---

## 2. Adaptive App Icon
- **Foreground**: Terracotta Anthropic asterisk logo centered in 66dp safe-zone.
- **Background**: Warm cream/parchment `#FAF9F5` or dark warm charcoal `#181816` subtle gradient.
